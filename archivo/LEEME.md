## `prototipo-traumatologia_4.html`

Prototipo navegable de un solo archivo, fechado 2026-08-28. Fue la
especificación visual y funcional a partir de la cual se definió la plataforma.
No se ejecuta ni se despliega: se abre con doble clic para consultar cómo se veía
y se comportaba una vista.

Contiene, además, cuatro fichas clínicas completas y bilingües (diáfisis femoral,
radio distal, LCA, luxación glenohumeral) que **por decisión D-016 no se cargan
en la base de datos**: la plataforma nace vacía y el contenido lo redacta el
traumatólogo desde el CMS. El archivo queda aquí por si alguna vez se quiere
recuperar ese material.

Ver `../BITACORA.md`, decisiones D-001 a D-007 y D-016.
